# Trabajo por roles

Lea #[[file:docs/GUIA_KIRO_EQUIPO.md]] y #[[file:.kiro/specs/_shared/DEPENDENCIAS.md]].

Respete ownership y rama. Integre en orden privacidad → contratos → motor → API → frontend → contenido → E2E. Si un bloqueo supera 30 minutos, acuerde mock/adaptador conforme a C0–C4. No marque tareas sin evidencia ni integre directo a `main`.
