# Archivo de la hackathon

Material de trabajo interno del equipo durante los tres días de la hackathon AWS Breaking Barriers (octubre de 2026). Se conserva como registro del proceso; no describe necesariamente el estado final del código. Para entender el proyecto, empieza por el [README principal](../../README.md).

| Carpeta | Contenido |
| --- | --- |
| [`equipo/`](equipo/) | Roles y responsabilidades, guía de colaboración con Kiro, división de tareas, plan de arreglos para la demo y la estructura de repositorio planificada al inicio. |
| [`producto/`](producto/) | Avances del rol de API y preguntas preparadas para la reunión con Fundación Integra. |
| [`rol1-backend/`](rol1-backend/) | Plan, pendientes y roadmap del rol de datos y motor de elegibilidad. |
| [`componentes/`](componentes/) | Descripciones iniciales de las carpetas `ia/` y `database/`, que finalmente se integraron en `backend/app/genai/` y `backend/app/db/`. |
| [`agent-tasks/`](agent-tasks/) | Planes, contexto y verificaciones de las tareas ejecutadas con agentes de IA durante el desarrollo. |

Las specs de Kiro siguen en [`.kiro/specs/`](../../.kiro/specs/INDICE.md) porque el código y los tests leen de ahí los contratos compartidos (`_shared/contracts/`).
